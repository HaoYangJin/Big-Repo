可复现命令：


## 工具限制

验证证据由调用方声明，不是防篡改证明；指纹不覆盖忽略文件、子模块内容和外部环境。验收工具不会替调用方运行验证命令。
展示检查默认离线，不保证外部服务可用，不覆盖所有 Markdown 扩展、HTML 和页内锚点。所有返回链接的查询与片段脱敏；报告不保存命令的原始 stdout/stderr 或令牌。
PR 查询只是只读观察，不将未知或等待状态标为通过；项目政策、授权和 GitHub 权限仍需真实核对。
