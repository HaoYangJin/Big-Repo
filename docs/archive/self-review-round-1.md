## 初审问题与修正

| 问题 | 本轮处理 | 验证方式 |
| --- | --- | --- |
| 默认流程停在 PR，与用户新的自动合并选择不一致 | 更新六技能协议、说明、模板和研究建议；版本升为 0.2.0 | 策略一致性检查与包清单检查 |
| 缺少可确定复核的合并门槛 | 增加只读 merge-readiness，绑定提交、分支、验证、独立审查和 CI | 正常与拒绝场景的临时仓库测试 |

| 验收说明尚未写入已完成的远端 CI | 区分首版已验证的 CI、当前提交 CI 和未验证的平台加载 | 核对 PR 检查和验收文档 |

## 固定的仓库玩法审查

- 增长与活动：不制造增长结论；本轮不向公开图表服务发送私有仓库标识。
- 状态展示：以真实 PR 检查为依据，不使用静态图片冒充实时成功。
- 项目门面：改善导航、直接使用示例和维护记录入口。
- 快速体验：提供可本地执行的测试和打包命令，不新建在线部署。
- 社区参与：沿用已有贡献指南和 PR 模板，不安装机器人。
- 项目故事：记录真实的这轮维护，不提前声称合并或公开已完成。

## 停止边界

只进行一轮审查、修正和复核，不持续追逐新优化。任何正式验证或必要权限失败即保留现场并交接，不继续合并或公开。公开不新增许可证，不发布 Release、不打标签、不部署；客户端实际安装加载仍单独标为未验证。
