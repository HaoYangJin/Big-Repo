## 本轮修正

| 初审观察 | 处理 | 可观察验证 |
| --- | --- | --- |
| 打包器使用固定临时文件名，可覆盖同名文件 | 使用独占创建的随机临时文件 | 预置同名文件在构建后保持原样 |
| ZIP 写入异常留下临时残件 | finally 清理本次暂存路径 | 写入异常、摘要异常、中断与发布失败注入 |
| ZIP 在摘要完成前就已替换旧包 | ZIP 与校验和均准备后再替换 | 摘要阶段故障不改变旧输出 |
| 校验和直接写入会跟随已有符号链接 | 原子替换链接本身 | 链接目标保留测试；无权限时明确跳过 |
| GitHub 只有源码，没有发行附件和下载导航 | 准备 1.0.0 ZIP、摘要、安装说明及 README 入口 | 发布后核对 Release、附件与匿名下载摘要 |

ZIP 与摘要分别原子替换，并非跨文件事务；第二次替换失败仍交接，分发前重新核对摘要。没有引入后台更新、定时 Actions、自动部署或公共插件市场提交。
